# InvoiceZen

> Dead-simple invoicing for freelancers fleeing QuickBooks bloat.

## What is InvoiceZen?

InvoiceZen is built for **Freelancers and micro-business owners (1-5 employees) currently paying for QuickBooks who only need invoicing, basic expense tracking, and payment collection**. Radical feature restraint as a feature — publicly commit to never adding payroll, inventory, or bank reconciliation. Positioning is the moat.

### Core MVP features
- One-screen invoice creation with instant send via email or link
- Automated payment reminders on day 3, 7, and 14 past due
- Stripe/PayPal payment collection embedded in invoice link
- Simple dashboard: paid, unpaid, overdue — nothing else
- CSV export for accountant handoff

**Pricing:** Flat monthly subscription, no per-invoice fees at $9/month or $79/year

## How this business runs itself (mailbox money)

The goal is passive, low-maintenance recurring revenue: AI is how we build and operate the business, not necessarily what it sells.

Invoice status updates via Stripe webhooks — zero manual checking. Overdue reminders fire via a nightly cron job with no human involvement. Customer support routed through an AI chat widget (OpenAI-backed) that resolves ~85% of questions from a static FAQ. Billing and subscription management handled entirely by Stripe Customer Portal. Owner's only recurring task: review a 5-minute weekly Stripe dashboard. Estimated owner time: under 1 hour/week.

**Estimated owner time:** ~1 hour(s)/week

**MVP estimate:** Next.js + Supabase + Stripe; 3 weeks solo dev including payment link generation and automated reminder cron jobs
